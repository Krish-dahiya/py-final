# Bookstore Inventory and Analytics System

## Features
- Add, remove and update books
- Record sales and reduce stock
- Calculate total and average revenue
- Create bar, line, pie and heatmap charts

## Files
- bookstore_system.py: main program
- inventory.csv: book details
- sales.csv: sales records
- requirements.txt: required libraries

## Run
1. Open this folder in VS Code.
2. Run `python -m pip install -r requirements.txt`
3. Run `python bookstore_system.py`
